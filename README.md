EFIs compatible with macOS High Sierra, Catalina, Big Sur and Mojave for the EVOO EVC141-12BK and other tongfang laptops.

- Don't try the High Sierra and Catalina EFI's if you're gonna use a newer version of macOS.
- Don't update the kexts or the OpenCore, you're gonna breake it (cuz it's for an old version of macOS)
- Generate an SMBIOS for a "iMacPro1,1" for macOS High Sierra and Catalina
- Generate an SMBIOS for a "MacBookPro16,3" for macOS Big Sur, Mojave and newer versions

--USB-- ❌ In macOS High Sierra the USBs had some troubles ; ✔️ In the other ones works propertly
--VRAM-- ❌ The VRAM doesn't goes more than 7mb in High Sierra and Catalina ✔️ In the other ones works propertly
--DEEPSLEEP-- ❌ It doesn't work in Catalina and High Sierra ✔️ In the other ones works propertly
--AUDIO-- ✔️ Audio Works Propertly

----------------------------------------------------------

- macOS Big Sur and Mojave works incredible fine with my EVOO EVC141-12BK, it should be the same for other tongfang laptops
- You can update some kexts, you can update Opencore with no issues
